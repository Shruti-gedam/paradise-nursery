# Paradise Nursery

Paradise Nursery is a React-based online plant shop where users can browse houseplants, add plants to a shopping cart, manage quantities, remove items, and view the total cart amount.

## Features

- Landing page with Paradise Nursery branding
- About Us page
- Plant categories
- Multiple houseplants
- Add to Cart functionality
- Dynamic cart item count
- Increase and decrease quantity
- Delete cart items
- Dynamic total price
- Checkout button
- Continue Shopping option

## Technologies Used

- React
- Vite
- JavaScript
- Redux Toolkit
- React Redux
- CSS
